02. DEBUGGING_DIARIES

When the compiler lies, I disassemble the binary.

cat fix_probe_bq2597x_rosemary.txt

ROOT CAUSE: Clang/LLVM (-O2) Dead Code Elimination. The bq2597x_charger_probe() function was stripped to a single ret instruction. The compiler detected Undefined Behavior (float types in kernel space breaking the FPU/NEON state).

SOLUTION: Replaced float arrays with integer fixed-point math (div_u64), added __attribute__((optnone)) to the probe function, and forced -O1 -fno-strict-aliasing in the Makefile.

RESULT: Probe successful. Charging current increased from hundreds of mA to ~4758 mA.
